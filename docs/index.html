Get Started

Select a download option on the left:

  • Release - the latest compiled version of the software (recommended).
  • .zip - a compressed folder containing the latest source for the application.
  • .tar.gz - the same source, as a .tar.gz archive.

If you want to view or contribute to the source, fork the repository on GitHub. Builds and tests run in GitHub Actions; there is no local development environment to set up.

Using the Release

  1. Download Vulnerator-<version>.zip and check its SHA-256 against the release page: 
    Get-FileHash .\Vulnerator-<version>.zip
  2. If Windows marks the zip as downloaded from the internet, right-click it, choose Properties, tick Unblock, then extract it. It is important that you extract all of the files.
  3. Run Vulnerator.exe from inside the extracted folder. To make a desktop shortcut, right-click Vulnerator.exe and choose Send to > Desktop (create shortcut).
  4. Choose Portable (a database next to the program) or Persistent (a database file you pick), then complete the one-time setup under Settings: your details, the eMASS export values and marking, the DISA STIG library and your eMASS IG/AP export.

Requirements: 64-bit Windows with .NET Framework 4.8. No installation and no administrator rights. Works on hardened DoD workstations: the database engine is winsqlite3.dll, part of Windows, and the program runs with .NET strong-name bypass disabled. It works offline; nothing contacts the internet unless you turn on Settings > Online Checks. The release zip also holds LICENSE.txt, THIRD-PARTY-NOTICES.txt, a per-file hash list for application allow-listing and Test-RealData.ps1, which checks a folder of your own files against a throwaway database.

What Vulnerator 2.0 Does

Imports

  • STIG checklists: .ckl, STIG Viewer 3 .cklb and Evaluate-STIG output (older results in Previous folders are skipped)
  • ACAS / Nessus: .nessus and CSV, from files, zips or folders of zips
  • SCAP / SCC XCCDF results and the DISA STIG library

NIST SP 800-53 Rev 5

  • Findings mapped to CCIs and Rev 5 controls (DISA CCI list, CNSSI 1253 baselines)
  • eMASS assessment procedures from your own IG/AP export, kept on your machine

Reports

  • eMASS POA&M and Hardware / Software import workbooks
  • STIG Details, PDF Summary, Risk Assessment Report, SCAP & STIG Discrepancies
  • Ports, Protocols & Services (PPSM starting point) and per-host STIG checklists

Handling

  • Classification / handling marking on every export
  • Labeled input files imported only after you confirm the label
  • Hardware, software, groups and ports managed in Configuration Management

Dashboards (free, included)

  • Open findings by severity, top hosts and compliance by NIST control family
  • POA&M aging, open/closed trend, assets with no scan or checklist
  • Outdated STIG checklists and active IAVMs - offline, with the classification marking
