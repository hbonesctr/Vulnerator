## Vulnerator 2.0 — 7.0.0 beta 9

**New Vulnerator 2.0 logo, and a fix for ACAS scans of hosts seen before with another address.**

- Fixed: an ACAS scan failed with "NOT NULL constraint failed: SoftwareHardware.Hardware_ID" when a host was already in
  the database (for example from an agent scan) with a different IP address, NetBIOS name or FQDN. Hosts are now
  matched by host name everywhere, so the scan imports; finding updates and the credentialed-scan flags (plugins 21745
  and 26917) no longer silently miss such hosts either.
- New Vulnerator 2.0 logo: application icon, window icons, About page and README. Source files (SVG and PNG) are in
  `docs/logo`.
