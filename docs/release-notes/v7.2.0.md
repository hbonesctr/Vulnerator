## Vulnerator 2.0 — 7.2.0

**Ports, protocols and services (PPS) from your ACAS / Nessus scans.** Tested on a real system as 7.2.0 beta 1 and 2.

### New report: Ports, Protocols & Services (Excel)
- **Ports Protocols Services sheet:** one row per port / protocol / service the scans observed: the service as Nessus
  detected it, your service name and acronym, the number of hosts, host names, IP addresses, groups, and the Nessus
  plugins that showed it (the evidence).
- **By Host sheet:** one row per host and port.
- Header row frozen, filter buttons, your marking in the header and footer. Only the group filter applies.
- A starting point for the system's PPSM registration.

### Configuration Management > Ports, Protocols, Services
- The tab now lists every port / protocol / service (it was empty: an unfinished part of the upstream 7.0 alpha), with
  the service as detected, service name, acronym and number of hosts.
- Select a row for its details and hosts; **Save Name / Acronym**, **Delete PPS** (asks first; a later scan that still
  shows it adds it back) and **Clear Selection**.

### Import
- Nessus port 0 results ("general/tcp", "general/icmp") are no longer stored as services; existing ones are removed on
  the first start of this version.
- Each port records which plugin(s) showed it on each host (scans imported before 7.2.0 show no plugins until
  re-imported).
