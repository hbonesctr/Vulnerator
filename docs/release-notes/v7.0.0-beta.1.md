## Vulnerator 2.0 — 7.0.0 beta 1

First pre-release of Vulnerator 2.0, the maintained fork of Vulnerator for current DoD RMF work. It is a beta: every
import and export is tested automatically on synthetic files in the build, but it has not yet been used on a real
system. Please report problems on the Issues page.

### Requirements
- Windows with .NET Framework 4.8 (included in current Windows 10 / 11 and Server 2016+). No administrator rights.
- Unzip the whole folder and run `Vulnerator.exe` from it. The build is 32-bit.

### What is new
**NIST SP 800-53 Rev 5**
- Controls, CCI-to-control mappings and monitoring frequency from the DISA CCI list (2026-07-14) and NIST OSCAL Rev 5
  (5.2.0); CNSSI 1253 confidentiality / integrity / availability baselines (no overlays).
- Assessment procedures: Settings > Import assessment procedures loads your eMASS IG/AP export (or any .xlsx / .csv with
  CCI and AP columns) and shows the AP and procedure text for each CCI. The data stays on your machine.

**eMASS exports**
- POA&M on the eMASS "RMF Standard" import template columns: one item per open rule or plugin, required fields filled
  from Settings > eMASS Export, completion dates by severity (30 / 60 / 180 days by default).
- Hardware / Software list export.
- Risk Assessment Report is now generic (no service-specific branding).

**Imports**
- Checklists (.ckl and STIG Viewer 3 .cklb), following the CKL-CKLB-Processor rules: statuses, severity overrides,
  rule dates, checklists without a host imported as STIG baselines.
- ACAS / Nessus (.nessus): hosts no longer bleed into each other, informational plugins are not open findings,
  software enumeration fixed.
- ACAS CSV: rebuilt; reads Tenable.sc "Vulnerability Detail List" and Nessus CSV exports (columns found by name).
- SCAP / SCC XCCDF results: rebuilt; SCC 4 and 5, XCCDF 1.1 and 1.2, host facts, scores.
- STIG library (Settings): rebuilt; the DISA quarterly library zip, a single STIG zip or one benchmark .xml. Checked
  against the October 2026 library (35 benchmarks, 2,889 rules). Loading a newer release never deletes rules your
  findings use, and older checklists no longer move a STIG back to an older release.

**Exports**
- CKL export (Configuration Management > host > STIG): every rule of the STIG with the host's results; re-imports
  cleanly.

**Behaviour and security**
- Works offline: nothing contacts the internet unless you turn on Settings > Online Checks.
- Logs include the reason for every error; unexpected errors are logged and the message names the log file.
- log4net 2.0.17 (CVE-2018-1285). Stray 2016/2018 SQLite DLLs removed from the program folder.

### Known limits
- SQLite: System.Data.SQLite 1.0.113 (SQLite 3.32). Migration to System.Data.SQLite 2.0 is planned for the next
  release.
- Screens other than Settings are unchanged from upstream Vulnerator 7.0.0 alpha and have not been reviewed with real
  data.
- CNSSI 1253 overlays (privacy, classified and so on) are not applied.

### Checking your files before relying on this build
`Test-RealData.ps1` is in the folder. It imports a folder of your files (.ckl, .cklb, .nessus, ACAS .csv, XCCDF
results, STIG library zips) into a throwaway database and prints one line per file; nothing leaves your machine:

```
powershell -NoProfile -ExecutionPolicy Bypass -File .\Test-RealData.ps1 -InputDir "C:\path\to\files"
```
