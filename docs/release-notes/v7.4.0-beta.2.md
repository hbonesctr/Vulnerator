## Vulnerator 2.0 — 7.4.0 beta 2

**Add-on licenses.** This beta prepares Vulnerator for add-ons that need a license. No add-ons are included, and
nothing changes if you don't use any.

### What's new
- **Settings > Integrations > Licenses**: paste a license key (**Add license**) or **Import .lic file...**. Each entered
  license can be removed.
- Each add-on shows its license status next to its name (for example "Licensed to ... until ..."). Each license shows
  what the installed add-ons say about it (valid, expired, not for this add-on, or not recognized).
- Licenses are kept in an **Add-on licenses** folder next to the database, so a portable copy keeps them.
- Vulnerator only stores licenses. Each add-on checks the signature and expiry of its own licenses on this computer;
  nothing is sent anywhere, so this works on air-gapped networks.
- A new or removed license takes effect right away, with no restart.

### For add-on developers
- Add-on interface **version 2** (`Vulnerator.AddOns.dll` 2.0.0) adds `IAddOnHost.Licenses`,
  `IAddOnHost.LicensesChanged` and the optional `IAddOnLicensing` interface (license status line and per-license
  description).
- Add-ons built for version 1 still load. The assembly version stays 1.0.0.0, so they bind without changes. An add-on
  built for version 2 is refused, with a clear message, by 7.4.0-beta.1.

### Tests
- The add-on test now also checks the following:
  - A version-1 add-on still loads.
  - Keys are stored and imported. Empty, binary and duplicate keys are refused, and removal works.
  - Add-ons see the licenses and are told when they change.
  - The Licenses box shows each add-on's status and descriptions.
