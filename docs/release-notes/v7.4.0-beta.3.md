## Vulnerator 2.0 — 7.4.0 beta 3

**Data for dashboard add-ons.** This beta keeps two details that imports used to lose and lets add-ons read more.
No add-ons are included, and reports do not change.

### What's new
- **ACAS risk factor kept.** Nessus Critical and High both become CAT I. Vulnerator now also keeps the risk factor, so
  add-ons can show Critical (Very High) separately. Scans imported before this version show as High until imported again.
- **Submitted STIG release kept.** When a checklist or SCAP result from an older STIG release is imported, its results
  still attach to the newer release already loaded. Vulnerator now also records the release, benchmark date, host and
  file each one was submitted with, so add-ons can list outdated checklists. Files imported before this version are
  not listed until imported again.

### For add-on developers
- Add-on interface **version 3** (`Vulnerator.AddOns.dll` 3.0.0). Add-ons built for versions 1 and 2 still load; an
  add-on built for version 3 is refused, with a clear message, by older Vulnerator versions.
- `FindingRecord`: `HardwareId`, `FirstDiscovered`, `SeverityLevel` (Very High, High, Moderate, Low, Very Low),
  `RiskFactor`, `SecondarySeverity` (DISA's stig_severity) and `References` (for example `IAVA:2026-A-0001`).
- `IFindingsData.GetStigSubmissions()`: submitted STIG release per file, host and STIG, the newest loaded release
  and whether the submission is outdated.
- `IFindingsData.GetPoamItems()`: the eMASS POA&M items as the eMASS POA&M export builds them.
- `IFindingsData.GetLastStigLibraryImport()`: when the DISA STIG library was last imported.

### Tests
- The add-on test now also imports a scan with a Critical finding and IAVB/IAVT references and an older-release
  checklist, and checks the new fields, the submitted releases and the POA&M items.
