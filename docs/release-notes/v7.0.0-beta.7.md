## Vulnerator 2.0 — 7.0.0 beta 7

**Fixes "Strong name validation failed" for System.Data.SQLite (beta 6) on hardened machines.**

Beta 6 switched to the SQLite built into Windows (`winsqlite3.dll`) by changing the library name inside
System.Data.SQLite. That change invalidated the library's strong-name signature, and the DoD .NET Framework hardening
setting `AllowStrongNameBypass = 0` makes Windows refuse such an assembly. The two SQLite assemblies are now shipped
unsigned (references updated to match), which loads under that setting.

The build now runs every test with `AllowStrongNameBypass = 0`.

Everything else is as in beta 6: 64-bit, SQLite from `C:\Windows\System32\winsqlite3.dll`, no native DLLs in the
program folder.
