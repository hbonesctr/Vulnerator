## Vulnerator 2.0 — 7.0.0 beta 11

**Licensing clean-up for the Vulnerator 2.0 release.**

- **Icons:** the app no longer ships the custom icon library from the original project, which contained Font Awesome
  Pro ("Light") icons that are licensed only to the original purchaser. Every icon now comes from the free
  MahApps.Metro.IconPacks Material pack (Material Design Icons). The icons look slightly different; nothing else
  changes. The download is about 17 MB smaller.
- **LICENSE.txt** (MIT, with the original 2017 copyright and the 2026 Vulnerator 2.0 line) and
  **THIRD-PARTY-NOTICES.txt** (every bundled library with its license, generated from the packages in the build) are now
  in the release folder next to Vulnerator.exe.
