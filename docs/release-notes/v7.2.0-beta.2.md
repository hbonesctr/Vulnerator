## Vulnerator 2.0 — 7.2.0 beta 2

**Fixes the empty Configuration Management > Ports, Protocols, Services tab.**

- The tab's list was bound to a name the screen does not have (an unfinished part of the upstream 7.0 alpha), so it
  stayed empty even though the data was there - the new report showed it. The list now shows every port / protocol /
  service from your scans, sorted by port, with the service as detected, your service name and acronym, and the number
  of hosts.
- Selecting a row shows its details and hosts. **Save Name / Acronym** stores the service name and acronym (used by
  the Ports, Protocols & Services report). **Delete PPS** removes an entry and its host links after asking (a later
  scan that still shows it adds it back). **Clear Selection** reloads the list.
- Buttons that did nothing (an unfinished per-host remove and "Add Hardware" box) were removed from this tab.
- The build now opens this tab's data the way the screen does, after importing the test scan.

Also in this version (from beta 1): the Ports, Protocols & Services report, and Nessus port 0 results no longer stored
as services.
