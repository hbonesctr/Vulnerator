## Vulnerator 2.0 — 7.0.0 beta 10

**Fixes the empty Reporting page.**

Reports and their filters (finding type, severity, status, group) are stored per Windows user. The database was
checked before Vulnerator knew who the user was, so on a new database (or the first launch of each new release folder)
they were created for a blank user name and the Reporting page showed no reports and empty filter lists.

- The user name is now set before the database is checked, so the reports are created for your account.
- The Reporting page creates any missing report settings for the current user when it opens, so existing databases
  are repaired automatically; no need to rebuild the database or re-import.
