## Vulnerator 2.0 — 7.0.0 beta 2

Second pre-release. Same features as beta 1, on a current SQLite.

### SQLite
- System.Data.SQLite 1.0.113 (bundled SQLite 3.32.1, 2020) replaced by **System.Data.SQLite 2.0.4** with
  **SQLite 3.53.4** (from the SourceGear.sqlite3 package). The Entity Framework provider moves to 2.0.3.
- `SQLite.Interop.dll` is gone. SQLite itself is the single file `e_sqlite3.dll` next to `Vulnerator.exe`; a newer
  32-bit build of that file (same name) updates SQLite without a new Vulnerator build.
- Existing Vulnerator databases open unchanged: dates are still stored the same way and foreign keys stay off, as
  before.

### Fixes found during the move
- Connection strings no longer have spaces around "=" (System.Data.SQLite 2.x would open an empty database).

### Tests added
- Entity Framework data loading as the Vulnerability Management screen does it.
- The build checks that `e_sqlite3.dll` is present and 32-bit, reports its SQLite version, and fails on leftover
  `SQLite.Interop.dll` / `sqlite3.dll` files.

### Known limits
- As in beta 1: screens other than Settings have not been reviewed with real data; CNSSI 1253 overlays are not applied.
- The upstream schema has foreign keys that do not match their parent tables; they are not enforced (as in every earlier
  version).
