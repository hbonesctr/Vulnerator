## Vulnerator 2.0 — 7.0.0 beta 4

### STIG library without the zip
- **Settings > STIG Library is now visible.** It was hidden in every earlier build (inherited from upstream).
- It takes the DISA library zip, or **many STIG zips / benchmark .xml files at once**, and shows when a library was last
  loaded into the open database.
- **Extract benchmarks from a library zip...**: on a machine where the library zip is allowed, writes its STIG benchmark
  .xml files (SCAP, OVAL, CPE and OCIL content skipped) to a folder. Move those files to the Vulnerator machine and load
  them with the STIG library buttons (search, select them all, then load).

### Ingestion warning
Importing checklists or SCAP results into a database with no STIG library loaded now asks before going on, and says how
to load one.

### Markings
- **Exports:** before every export (eMASS POA&M, Hardware / Software list, Risk Assessment Report, STIG Discrepancies,
  Excel report, CKL) Vulnerator asks you to accept or change the marking, prefilled from Settings (the last one used).
  It is printed at the top and bottom of every sheet, stored as the workbook's "Classification" property, and written
  as the CKL MARKING. The question can be turned off in Settings.
- **Labeled inputs:** a workbook carrying a sensitivity label (for example an eMASS IG/AP export) is shown with its label
  and imported only after you confirm. Encrypted (protected) files still cannot be read; save an unprotected copy.
