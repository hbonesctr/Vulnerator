## Vulnerator 2.0 — 7.2.0 beta 1

**Ports, protocols and services (PPS) from your ACAS / Nessus scans.**

### New report: Ports, Protocols & Services (Excel)
- **Ports Protocols Services sheet:** one row per port / protocol / service the scans observed, with the service name
  as Nessus detected it, your service name and acronym (set them under Configuration Management > Ports, Protocols,
  Services), the number of hosts, the host names, IP addresses, groups, and the Nessus plugins that showed it on those
  hosts (the evidence).
- **By Host sheet:** one row per host and port.
- Header row frozen, filter buttons, your marking in the header and footer. Only the group filter applies.
- A starting point for the system's PPSM registration.

### Import
- Nessus files host-level results under port 0 ("general/tcp", "general/icmp"). Those are no longer stored as
  services, and existing port-0 entries are removed from your database on the first start of this version.
- Each port now records which plugin(s) showed it on each host. Ports in scans imported before this version have no
  plugins listed until the scan is imported again.

### Tests
- The build now checks the PPS data from the test scan (no port 0, 22/tcp ssh on the right host, evidence plugin) and
  the new report's sheets and totals.
