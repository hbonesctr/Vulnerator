## Vulnerator 2.0 — 7.0.0 beta 8

**Import from zip files and folders, Evaluate-STIG support, and the Help pages.**

### Importing (Vulnerability Management > Ingest)
- The import menu is now a **File Type** list with two buttons: **Add Files / Zips...** and **Add Folder...**.
- **Import ACAS** reads .nessus and CSV files from zip files and folders (subfolders and zips inside zips included). A
  folder of zip files, each holding a .nessus file, is read in one step.
- **Import CKL / CKLB** (renamed from "Import CKL") reads .ckl and .cklb files from zip files and folders. Anything under
  a folder named **Previous** is skipped: Evaluate-STIG keeps older results there and the current ones in **Checklist**.
  A message reports how many files were skipped.
- Fixed: the file picker opened a second time after a selection. A double-click in the picker could click the import
  button underneath it again; the picker now ignores that click.
- Fixed: a checklist with no host name (a STIG baseline) was reported as "processing failed" and turned the ingestion
  result into a warning. It is now logged as a baseline import and counts as processed.
- The same file is queued only once; zip contents are extracted to a working folder under %TEMP% that is removed after
  a day.

### Vulnerator 2.0
- Window title, About page and file properties now read **Vulnerator 2.0**.
- About > Contributors adds **Hector L. Bones — Vulnerator 2.0 application rewrite**.
- **Help** is back in the left menu, with rewritten pages: Getting Started, Using the Software (imports, findings,
  exports, markings), Error Reporting (where the log is) and the 2.0 change log.

The version number stays 7.0.0 (beta 8) so update checks keep working; the product name is Vulnerator 2.0.
